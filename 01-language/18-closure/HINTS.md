# Hints

<details>
<summary>Hint 1</summary>

`func() int { ... }`は、外側の関数で宣言した変数を読み書きできます。

</details>

<details>
<summary>Hint 2</summary>

`Counter`の中で`count := 0`を宣言し、返す関数の中で`count`を増やします。

</details>

<details>
<summary>Hint 3</summary>

`Counter`を呼ぶたびに新しい`count`が作られるので、カウンタ同士は値を共有しません。

</details>
