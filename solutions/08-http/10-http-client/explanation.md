# Why?

200の本文"Go"は"Go"として返し、503はerrorです。Client.DoはHTTP error statusをGoのerrorにしないため別に検査します。

# Alternatives

別の書き方も、同じ入力・出力とエラー契約を満たせます。模範解答と自分のコードを比較し、読み手が追う状態や分岐が増えていないか説明してください。

# Idiomatic Go

HTTP応答の本文を所有する側が必ずcloseします。

# 振り返り

テストが示す具体例を一つ選び、入力から出力まで手で追ってください。境界値のテストを一つ自分で追加してから、もう一度解いてみましょう。
