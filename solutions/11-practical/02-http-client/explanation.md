# Why?

1ページ目[a,b]/next=2と2ページ目[c]/next=0は[a,b,c]になります。各requestの本文をループ内で閉じて、ページ数に比例して接続を保持しないようにします。

# Alternatives

別の書き方も、同じ入力・出力とエラー契約を満たせます。模範解答と自分のコードを比較し、読み手が追う状態や分岐が増えていないか説明してください。

# Idiomatic Go

ループ内の資源はその反復で閉じ、全体の期限はcontextで伝えます。

# 振り返り

テストが示す具体例を一つ選び、入力から出力まで手で追ってください。境界値のテストを一つ自分で追加してから、もう一度解いてみましょう。
