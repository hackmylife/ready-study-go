# Why?

POST {"text":"learn Go"}で{id:1,text:"learn Go"}が作られ、GET /notes/1で同じ内容を読めます。mutexはmapとID採番を一緒に保護し、JSONの書き込みはlockの外で行います。

# Alternatives

別の書き方も、同じ入力・出力とエラー契約を満たせます。模範解答と自分のコードを比較し、読み手が追う状態や分岐が増えていないか説明してください。

# Idiomatic Go

入力検証・状態更新・HTTP応答を短い区間として分けます。

# 振り返り

テストが示す具体例を一つ選び、入力から出力まで手で追ってください。境界値のテストを一つ自分で追加してから、もう一度解いてみましょう。
