# Why?

id="u1"から"Aki"を得ると"Hello, Aki"を返します。挨拶を作る利用側がNameだけを必要とするため、ここに小さなinterfaceを置きます。

# Alternatives

Name取得だけなら関数引数も候補です。複数methodを必要とするまとまりになった場合にinterfaceが自然かを考えてください。

# Idiomatic Go

interfaceは利用側で定義し、実装側は暗黙に満たせます。
