# Why?

固定時計が2026-01-02 03:04:05 UTCを返すと"2026-01-02T03:04:05Z"になります。隠れたtime.Now依存をなくすと再現可能なテストを作れます。

# Alternatives

別の書き方も、同じ入力・出力とエラー契約を満たせます。模範解答と自分のコードを比較し、読み手が追う状態や分岐が増えていないか説明してください。

# Idiomatic Go

依存を引数に出すと呼び出し元が実装を選べます。

# 振り返り

テストが示す具体例を一つ選び、入力から出力まで手で追ってください。境界値のテストを一つ自分で追加してから、もう一度解いてみましょう。
